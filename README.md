## 🧭 About me

I build full-stack applications end to end, connecting thoughtful interfaces with dependable backends. With **5+ years of experience**, I focus on turning ideas into maintainable software that is ready for production and built to evolve.

- **Frontend & interactive experiences** — I enjoy building engaging, interactive interfaces with React and Next.js, and bringing 3D experiences to the web with Three.js and React Three Fiber. Explore my portfolio [maciej-koch.com](https://maciej-koch.com).
- **Architecture & code quality** — clear boundaries, readable code, and pragmatic decisions that support long-term maintenance.
- **Backend & REST APIs** — well-structured services, clear API contracts, and reliable data flows.
